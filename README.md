# Sukun – Voice of Faith

*A React + Vite Naat Listening App*

> A fast, minimal, and elegant web app to stream beautiful naats online.

🎧 [Live Demo](https://sukun01.netlify.app/)

---

## Overview

**Sukun – Voice of Faith** is a clean and responsive Naat Listening Web App built with **React** and **Vite**. <br> It offers smooth streaming, fast performance and a developer-friendly codebase with ESLint support.


## Features

* 🎶 Stream naats instantly
* ⚡ Lightning-fast with Vite + React
* ✅ ESLint-configured for clean code
* 📱 Mobile-first responsive design
* 🔧 Easy to extend and customize
